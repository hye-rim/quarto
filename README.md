# 쿼토 🔷

보드게임 「쿼토(Quarto)」를 컴퓨터와 1:1로 하는 게임. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `game.js`).

- **말 16개**: 네 가지 속성이 모두 다르다. 크기(큰 말/작은 말), 색(파랑/주황), 모양(네모/동그라미), 구멍(있음/꽉 참). 위에서 본 그림이라 큰 말은 크고 그림자가 두껍게 그렸다.
- **한 차례**: 상대가 골라 준 말을 4×4 판의 빈 칸에 놓고, 남은 말 중 하나를 골라 **상대가 놓을 말**로 건넨다. 첫 차례는 말을 건네기만 한다. 판마다 먼저 건네는 쪽이 바뀐다(연습은 컴퓨터가 먼저 건넴).
- **승리**: 말을 놓아 가로·세로·대각선 한 줄 4개가 **한 가지라도 같으면**(모두 큰 말, 모두 파랑…) 놓은 사람이 이긴다. 16개를 다 놓아도 없으면 무승부.
- **정해 둔 것**: 이긴 줄은 자동으로 판정한다("쿼토!" 외치기, 상대가 놓친 쿼토 가로채기 없음). 2×2 정사각형 규칙(상급 규칙)은 넣지 않았다.
- **👀 위험한 말 표시**: 켜면 건넬 차례에 "주면 상대가 바로 이기는 말"에 ✖ 가 붙는다. 켠 판은 전적에 넣지 않는다.
- **컴퓨터**: 쉬움은 이길 수를 35% 놓치고 40% 확률로 아무 말이나 건넨다. 보통은 이길 수를 놓치지 않고, 바로 지는 말은 건네지 않는다. 어려움은 (놓을 칸, 건넬 말) 짝마다 세 수 앞(놓기 기준)을 탐색하고, 빈 칸이 9개 이하면 끝까지 읽는다(노드 한도 40만). 컴퓨터끼리 40판(먼저 건네는 쪽 번갈아): 보통 대 쉬움 34:2(무 4), 어려움 대 쉬움 38:1(무 1), 어려움 대 보통 32:0(무 8). 어려움의 한 수는 길어야 0.3초.
- **연습(튜토리얼)**: 컴퓨터는 이기는 칸에 놓지 않고, 사람이 이길 수 있는 말이 있으면 그 말을 건넨다.
- **저장**: 난이도별 전적 `quartoRec`(도움 없이 한 판만), 로비 표시용 총 승수 `quartoWins`, `quartoMuted`.

시험은 `node --test`(`test/logic.test.js`): 공통 속성 판정(있음·없음 비트), 줄 10개, 건네기와 놓기 순서(차례·쓴 말·빈 칸), 승리와 이긴 줄 설명, 무승부, 컴퓨터의 즉시 승리, 보통·어려움이 안전한 말이 있으면 위험한 말을 안 건네는지, 연습 컴퓨터, 난이도 순서(고정 난수), 모든 난이도가 끝까지 두는지.
